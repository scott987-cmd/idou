# 自建企业应用平台（不依赖妙搭）

这是产品方向与实施边界，不代表发布平台已经完成。

## 用户入口

不新增一级「妙搭」导航。入口放在「编程任务」：描述需求 → Agent 生成源码 → 浏览器运行预览 → 对话修改 → 验收 → 发布到企业应用目录。一般员工可以使用企业模板做表单、看板和流程工具；开发者可以查看源码、运行命令和排查问题。

当前已接入桌面任务、工作目录文件查看、独立本地 HTML 预览，以及[本机不可覆盖版本包、服务端待审目录、确认云盘归档及客户端取回校验](app-candidates.md)。目录只记录元数据、支持创建者查看和撤回；[企业审核人现可查看其他作者的清单并通过/退回](app-reviews.md)，结论绑定不可变版本，不代表源码安全审查或发布许可。归档上传复用企业预算，在隔离替身链路验证了保留包精确上传、一次性许可、缺失本机包取回和篡改拒绝。客户端校验读取字节及清单/包哈希，但尚未验收真实企业云盘或发布节点独立验证。服务器发布、共享运行应用目录、可视化设计器与业务数据库还未实现。

## 服务端不是一个混合执行进程

归档版本现可在内置浏览器临时预览：每次打开/刷新都重新下载并验哈希，页面只服务已校验包内字节，不混入最新工作目录。最多 5 分钟后销毁，错误不回退缓存；不增加上传或预算占用。这是客户端静态快照能力，不是企业托管或 OS 级多租户执行沙箱。

另已实现[独立 Docker 静态运行节点的开发验收入口](isolated-app-runtime.md)：固定镜像、无挂载/外部网络、只读非 root、CPU/内存/PID 限额，容器独立校验版本包，网关再次核验响应字节，实际浏览器交互与退出清理通过。当前由管理员提供本地包，未接通发布授权、独立飞书取包、企业访问域名或后端运行，不能视为生产发布完成。

[临时运行授权](app-runtime-authorization.md) 现已连接控制服务与该节点：默认关闭的运行操作员配置、短期精确版本许可、单次领取、资源读取时校验和闲置撤销检查；实际 CLI/HTTP/SQLite/Docker 链路已验收。这仍是运行验收，不是员工可访问的正式应用发布。

桌面「应用运行验收」现可列出可验收版本、查看精确节点/镜像/文件清单，经目录选择和原生确认导出私有短期许可；该导出已在真实节点消费验证。许可内容不传入网页渲染进程；没有自动启动、远端文件传输或一键发布。

| 组成 | 职责 | 明确禁止 |
| --- | --- | --- |
| 现有控制服务 | 飞书登录、租户/成员/角色、模型密钥、技能中心；扩展应用目录、版本元数据、发布审批、配额与审计 | 直接执行用户生成的应用代码；把上游模型密钥发给应用 |
| 隔离构建与运行节点 | 按应用/租户隔离构建，运行静态站点或后端服务；限 CPU、内存、时间、网络与磁盘 | 挂载宿主密钥、飞书 CLI 登录目录、控制服务数据库或任意企业共享目录 |
| 应用数据服务 | 对有持久业务数据需求的应用提供租户隔离的数据库与访问策略 | 将个人文档、聊天推导知识自动变成共享应用数据 |

初期可在企业同一部署集群内提供这些组件，但必须分进程/容器和权限。现有服务端负责平台管理，不能因为已经有服务端，就把未经验证的生成代码加载到控制服务里。

## 存储与原有 LLM Wiki 方案的关系

- 飞书文档仍是知识原文。Wiki 派生分片和生成媒体仍走飞书云盘，不为知识新增服务端正文存储。
- 应用源码版本和发布包可以使用客户指定的飞书云盘目录，记录内容哈希、构建版本、依赖锁和生成者；运行节点持有可重建缓存。
- 应用业务记录优先复用飞书多维表格/API。在并发、事务、结构化查询需求超过它的能力时，再使用企业部署的独立数据库。业务数据库不等同于 Wiki 存储，不能隐含改变知识权限模型。
- 应用发布包占用与 Wiki 占用分别计量，受企业总云盘预算约束；运行缓存另设磁盘上限。构建输出不能绕过已有云盘预算。

## 从预览到发布的门槛

1. 锁定待发布的源码修订、依赖、构建命令、运行类型和产物哈希；不能将「最近一次构建成功」套用到当前未提交修改。
2. 在隔离节点构建并测试。限制外网依赖来源，不自动读取开发者机器上的密钥。
3. 显示应用访问范围、飞书/模型权限、业务数据源及预计资源用量，获得明确发布确认。发布不隐含授权通讯录、全部聊天或所有企业文档。
4. 创建不可变版本；发布环境按指定版本切换，支持回滚和健康检查失败恢复。首次发布不能替换其他同名应用。
5. 生成企业内部访问地址，运行身份使用短期凭据和限定权限。最终用户身份应传递到数据访问层，不能用应用管理员身份代替所有访问者。

## 开发顺序

1. 本地闭环：桌面编程任务、真实模型生成、文件成果、隔离浏览器、继续修改与任务恢复。
2. 平台控制：应用清单、模板、版本、发布意图与审批、统一身份和权限。
3. 企业运行：构建队列、隔离节点、内网域名/TLS、健康检查、回滚与运维可见性。
4. 业务能力：飞书数据连接、可选数据库、事件/定时工作流、可视化组件编辑。

企业实际集群、域名、证书和数据库由部署阶段配置，不在开发过程中擅自创建外部云资源。私有化飞书 CLI 到位后只替换 Feishu Provider，不能把应用平台绑定到某个 SaaS 独有功能。
