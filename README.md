# i豆 · 飞书用户的企业桌面 Agent

**工作、编程、企业问答，一台搞定。** 管理员完成服务部署与飞书应用授权后，员工使用飞书 OAuth 登录，在同一个窗口里发消息、改文档、做网站、查知识、写代码。默认逐次确认；完全访问只授权当前任务。

## 能做什么

- **飞书消息**：一句话，替你发出去；标准权限先显示确认卡，只有你为当前任务主动开启完全访问后才连续执行。
- **飞书文档**：边看边改，改动直接写进飞书文档。
- **本地文件**：读你电脑上的表格、文档和 PDF，算好的报告写回原来的文件夹。
- **图片视频**：说一句就生成；默认先告诉你模型和规格，视频每次都问你。
- **文档网站**：说需求，它写好网站并发布；谁能打开由你选。
- **小游戏**：一个模板，改成你的游戏，改完就能玩。
- **企业知识**：问公司制度，答案带出处；只查你有权读的资料。
- **定时任务**：说好做什么、几点做，到点自己跑；报告存进你的云空间，还能照你选好的，自动写进文档、发到群里。
- **浏览器自检**：做完，它自己打开网页检查一遍。
- **操作电脑**：看得见屏幕，也动得了手；默认要进哪个应用操作，先问过你。

## 为什么是 i豆

- **站在 Codex 的肩膀上**：Agent 内核随 Codex 持续升级。
- **可以用客户自己的大模型**：接入企业自有或指定的模型服务；当前已经通过服务端网关接入 MiniMax-M3 和 GLM-5.3。
- **能力跟随开源飞书 CLI**：随附并锁定 `larksuite/cli`，通过 provider 契约接入。
- **复用飞书 OAuth 身份**：知识回答只引用本次查询中重新核验成功的候选来源。
- **个人知识副本边界清楚**：当前上限 1000 篇 / 64 MiB，本地加密，不要求额外检索集群；更大规模集中索引仍在路线图中。
- **飞书 SaaS 今天就能用，私有化按契约接入**：飞书 SaaS 已经随附；私有化环境作为另一个接入方式按同一套契约添加。
- **默认逐次确认，完全访问按任务授权**：发消息、写文档、发布网站默认先弹确认卡；完全访问只作用于当前任务（生成视频仍每次询问）。
